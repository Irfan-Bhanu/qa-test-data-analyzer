**QA Test Data Analyzer**
QA + Data project: Analyze test results using Python (CSV, Excel, Data Cleaning)

🚀 **Project Overview**
This project analyzes test execution results from CSV/Excel files.
It performs:
* Data cleaning (handling spaces, casing issues)
* Pass/Fail calculation
* Failure percentage calculation
* Risk classification (Stable / Warning / Critical)

 📂 **Project Structure**
* `project/` → Main working code
* `practice/` → Daily learning files
* `data/` → Input data files

 ▶️ **How to Run**
```bash
python project/test_analysis.py
```

 📊**Sample Output**
Pass: 2
Fail: 2
Status: Warning

 🛠 **Tech Used**
* Python
* Pandas
* CSV handling
