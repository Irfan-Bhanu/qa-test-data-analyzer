# Week 4 – API Testing 

##  Overview

This week focuses on API testing using Python `requests` library and validating API responses.

---

##  Topics Covered

### 1. GET Request

* Fetch data from API
* Validate status code
* Parse JSON response

---

### 2. Loop Testing (Multiple APIs)

* Dynamic API calls using loop
* Validate multiple records
* Pass/Fail reporting

---

### 3. POST Request

* Send data to API
* Validate response (201 Created)
* Verify returned data

---

### 4. PUT & DELETE

* Update existing resource (PUT)
* Delete resource (DELETE)
* Validate response codes

---

### 5. Data Validation

* Check missing values
* Validate data types
* Detect duplicate entries

---

### 6. UI vs API Validation

* Fetch data from UI using Selenium
* Fetch data from API
* Compare UI vs API values

---

##  Key Learnings

* API automation using Python
* JSON parsing and validation
* Data quality checks
* End-to-end validation (UI + API)

---

##  Outcome

✔ Ability to test APIs using Python
✔ Validate real-world data scenarios
✔ Combine UI automation with API testing
