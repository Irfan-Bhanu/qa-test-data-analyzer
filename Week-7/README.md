**AI-Based Test Prioritization System**
**Problem**

Running all test cases is time-consuming. Need to identify high-risk test cases early.

**Solution**

Built a Machine Learning pipeline to:

Predict test failures
Detect anomalies
Rank test cases by failure probability

**Models Used**
Logistic Regression (baseline)
Decision Tree (interpretability)
Random Forest (final model)
Isolation Forest (anomaly detection)

**Key Features**
Failure prediction (Pass/Fail)
Feature importance analysis
Anomaly detection for unusual test runs
AI-based test prioritization

**Outcome**
Reduced test execution effort
Identified high-risk modules
Enabled smarter test execution strategy
